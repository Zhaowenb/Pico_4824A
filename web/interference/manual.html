目的

先读：本实验要回答什么

把发射同步的大信号与晚到的真实导波分开，寻找四类证据：拉线棒浮动/电场共模、TX/RX 公共阻抗、TX 线圈对接收回路的磁近场，以及真实机械导波/PZT 响应。

当前已知 TX 线圈负极与 PZT 接收负极直流导通；PZT 与棒可以绝缘或约 0～2 Ω 低阻连接。已有现象是接棒通常减小干扰，而靠近 TX 时改善变弱。本手册通过可重复的对照验证这些解释，不把单次波形变化直接当成机制证明。

所有实验默认固定 75 kHz、Hann 周期数、AWG 幅值、功放增益、偏置磁场、通道、采样率、量程和触发。页面只控制 Pico/AWG；移动探头、换线、电阻和屏蔽都由实验者完成。
准备

01 · 实验前准备

  1. 确认信号路径。画出 Pico AWG → 功放/匹配网络 → TX 线圈，以及 PZT± → RX/Pico。标出 TX−、RX−、BNC 屏蔽、USB、供电负极与棒。记录当前“棒浮空”和“棒低阻接 RX−”的实际连接。
  2. 确定三路信号。选 RX 波形通道、棒电压探头通道、激励参考/触发通道，三者必须不同。棒电压实验使用高输入阻抗探头；填写倍率与地线位置。没有可靠激励参考时，采集后在波形上手工标记 t₀。
  3. 检查输入条件。功放高压输出不可直接接 Pico ADC；只能使用符合设备额定值的监测、衰减或隔离路径。Pico BNC 通道地不是彼此隔离的。选择不会溢出的量程，检查探头倍率与物理连接。
  4. 固定实验常量。记录 Hann 周期数、AWG Vpp、功放面板增益、偏置磁场、TX/PZT 位置、RX 引线和触发阈值。每项实验只改变该实验指定的变量。
  5. 准备实验材料。低阻连接件和电阻组、尺、双绞/屏蔽双绞线、可调回路、PZT 等效电容、开槽静电屏蔽板、记录实际回流路径的草图。
  6. 选择重复次数。每条件 3～5 次，默认 3 次。若波形漂移或接触不稳，先排查后重新采集；不要把异常点静默删除。
每次改接线前停止激励并确认功放输出状态。不要断开设备保护接地；不要用软件中的 ADC 量程替代硬件输入保护。参见原项目《配置与使用说明》的输入安全要求。
跟做

02 · 页面操作：从开机到完成一项实验

  1. 启动服务。在 Pico_4824A_btf 目录运行 start_web.ps1，再从 WaveGuard 打开“干扰类型判别实验”。本手册可离线阅读；采集页面必须经本机服务打开。
  2. 建立会话。页面会读取 WaveGuard 保存在当前浏览器中的设置。核对 RX、棒、参考通道、倍率、量程、采样率、触发、Hann 周期数和 AWG Vpp。实机采集时关闭“仿真采集”；确认后点击“确认并锁定配置”。
  3. 设置时间窗。确认触发前有足够基线，记录长度覆盖尾振及期望回波。回波窗按真实传播时间填写；不确定时可以先留空，之后从原始数据重算。
  4. 打开左侧实验。阅读目的、接线步骤和当前条件。按照页面清单逐项核对，填写实际电阻/面积/角度/接线描述和备注。
  5. 采集当前条件。点击“开始当前条件”，在弹窗中再次确认物理接线。完成后查看波形和溢出状态；需要时点击波形标记激励起点 t₀。波形有效才点击“保存当前条件”。
  6. 完成重复。同一条件重复 3～5 次；页面显示已保存次数。达到目标后点击“下一条件”，按新的条件先停止激励、再改接线。所有条件满足次数后点击“完成实验”。
  7. 读图与归档。查看条件波形/频谱、均值±标准差、抑制比、拟合和当前实验结论。全部 12 项完成后看综合证据，并导出 CSV、JSON；原始 NPZ 和 FFT NPZ 已在 TARGET 本机目录自动保存。

中途刷新可自动恢复最近会话；顶部“新建会话”不会删除旧数据。旧会话可用页面中的 32 位会话编号恢复。完成实体接线的确认由实验者负责，网页无法检测接线是否真的改变。

计算

03 · 时间窗和指标怎样设置

四个统一窗口

基线窗
t₀ 前无信号区，默认 −50～−5 μs；用于估计直流偏置与噪声 RMS。
发射窗
t₀ 至 t₀+N/75 kHz。例如 5 周期约 66.7 μs。
尾振窗
发射结束后紧接的一段，默认长度 200 μs；应避开真实回波。
回波窗
人工输入起止，必须落在记录内并晚于发射窗。移动 PZT 后检查传播延迟是否改变。

每次采集计算

  • 峰值 A=max|V|；RMS sqrt(mean(V²))。
  • 能量 E=∫V²dt，按实际采样间隔数值积分。
  • 回波信噪比 20log₁₀(A_echo/V_noise,rms)。
  • 75 kHz 分量 2/N · |ΣV[n]e^(−j2π·75000n/fs)|，相位取复数辐角。
  • 发射、尾振、回波各保存完整 FFT：频率、幅值、相位。

程序先扣除基线平均电压，再算这些指标。若回波窗留空，回波/SNR 不计算。若窗口超出记录范围，保存会报错；增大采样时长或调整窗口。若输入溢出，幅值比较不可靠，应调整硬件衰减或安全量程后重测。

结论

05 · 怎样合并证据

四组机制

  • 棒浮动 / 电场共模：接棒抑制、电阻扫描、高阻探头测得棒/RX 同步、静电屏蔽改善。
  • 磁近场：接棒后残余随距离降低、双绞改善、面积和方向依赖。
  • 公共阻抗：经核实的 Star/Kelvin 回流改善、公共地长度影响。
  • 机械导波：真实 PZT 的晚到回波、Dummy 对照、去机械耦合后晚到回波消失及传播延迟一致性。

读结论的顺序

  1. 先确认每条件重复数够、无溢出、激励和窗口一致。
  2. 先看同一实验内的波形和均值±标准差，再看 dB 或拟合。
  3. 单一对照只能支持机制，不能给出绝对物理占比。
  4. 若多个变量同时变了，在备注中标记，必要时重做对照。
  5. 将“强/中/弱/未观察到”当证据分级，不当作四类贡献百分比。

文件内容用途

改变统一基线、尾振或回波窗后，使用“用当前窗口重新分析已存数据”；这会更新指标和 FFT 文件，不改写原始波形。单次 t₀ 可在待保存波形上标记。若需要完全不同的采样设置，建立新会话，避免跨条件比较不同仪器配置。

排查

07 · 常见问题与处理

页面打不开或按钮无响应
确认 WaveGuard 本机服务仍在运行，并从主工作站进入干扰实验；直接双击采集页 HTML 无法调用本机 API。
等待触发后报错
确认参考通道已接入有效低压监测信号、触发阈值位于量程内、触发沿与脉冲一致。不要为绕过错误而随意关闭触发。
保存提示窗口超出记录
检查 t₀、触发前比例、采样时长、尾振和回波窗，确保所有窗口完整落在波形内。
回波指标为空
先填写回波开始/结束，再点击重新分析；窗口必须完整落在当前记录内。
原始波形与图上的点数不同
绘图使用降采样预览，指标、原始 NPZ 和 FFT 由完整采样计算。
两个条件看起来差很多，但页面说证据不足
先确认重复数、溢出、实际接线记录和拟合所需的多个参数点；相关和经验拟合不是唯一机制证明。
Star/Kelvin 没改善
核查长 BNC 屏蔽、USB、机壳和供电线是否仍构成并联公共回流；若实际回流未分开，不能用该负结果排除公共阻抗。
