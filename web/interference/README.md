# WaveGuard 干扰类型判别实验

在 TARGET `Pico_4824A_btf` 运行 `start_web.ps1`，然后访问 <http://127.0.0.1:4824/interference>。本目录资源必须由 WaveGuard 本机服务提供；直接双击采集页无法访问采集接口。

完整图文操作手册在 <http://127.0.0.1:4824/interference/manual>，对应本目录的 `manual.html`。手册本身可以双击离线阅读和打印；主采集页内也显示当前条件的逐步核对清单，四项均确认后才能开始采集。手册中的实验按钮可直达主页面对应实验。

首次使用请核对 RX、棒电压和激励参考通道及量程，填写适合当前拉线棒传播时间的回波窗口。页面默认读取 WaveGuard 保存在同一浏览器中的设置，并强制使用 75 kHz Hann 激励。激励起点可在采集后点击波形标记。更换接线后，逐次确认并采集；每次原始波形、完整 FFT 和指标保存在 TARGET 的 `data/interference/<会话编号>/`。页面刷新后自动恢复最近会话，也可输入编号恢复其他会话。新建会话不会删除已有记录。

`runs/*.npz` 是完整原始采样，`runs/*_fft.npz` 是发射、尾振和回波窗口的完整频率、幅值、相位，`session.json` 包含配置、人工变量、逐次指标、重复采集统计所需数据。CSV 按钮导出逐次指标汇总，JSON 按钮导出当前会话记录。仿真采集仅用于验证页面流程，不应用于物理判别。

回波窗未设置时回波指标与机械证据留空；输入溢出时记录会标记为不可用于可靠幅值比较。证据分级是规则化提示，不代表各耦合机制的能量占比。
